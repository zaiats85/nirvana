# Conventional Commits Guide

## 📝 Format
```
type(scope): description

[optional body]

[optional footer(s)]
```

## 🏷️ Valid Types

| Type | Description | Example |
|------|-------------|---------|
| `feat` | New feature | `feat: add user authentication` |
| `fix` | Bug fix | `fix: resolve null pointer exception` |
| `docs` | Documentation | `docs: update API documentation` |
| `style` | Code style changes | `style: format code with prettier` |
| `refactor` | Code refactoring | `refactor: simplify auth logic` |
| `perf` | Performance improvement | `perf: optimize database queries` |
| `test` | Adding tests | `test: add unit tests for user service` |
| `build` | Build system changes | `build: update webpack config` |
| `ci` | CI/CD changes | `ci: add automated deployment` |
| `chore` | Maintenance tasks | `chore: update dependencies` |
| `revert` | Revert previous commit | `revert: revert feat: add user auth` |
